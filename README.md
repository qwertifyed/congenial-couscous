## Описание

Одностраничный сайт с информацией об авторе, списком навыков,
проектами и контактами.

## Технологии

- HTML5 — структура страницы;
- CSS3 — оформление;
- JavaScript — обработка нажатия кнопки;
- Git и GitHub — контроль версий и публикация проекта.

## Структура проекта

```
congenial-couscous/
├── index.html   — разметка страницы
├── style.css    — оформление
├── script.js    — простой скрипт
└── README.md    — описание проекта
```

## Запуск

Откройте файл `index.html` в браузере.
